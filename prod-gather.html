    상품 정보 조회

    POST https://api.shopling.co.kr/prod/prod_gather_api.phtml?mode=2 호출 방식

    요청

    필드설명타입형식최대필수비고
    <reqst>
    <apiProdGather>
    login_id로그인IDCDATAY
    company_id고객사 아이디YshopPling 발급
    api_auth_keyAPI 인증코드YshopPling 발급
    partner_id제휴사 전용 (샵플링 발급)
    search_tp검색일 기준(등록일, 수정일, 판매상태변경일) 택일CDATAY검색 기준 2018.7.19 추가(등록일, 수정일, 판매상태변경일 중 택 1) 없을시 등록일 기준
    start_dt검색시작일자yyyymmddY3개월 이상 넘길수 없습니다.
    end_dt검색종료일자yyyymmddY
    key_search_tp코드 검색 기준(상품코드, 자사코드) 택일CDATA검색 기준 2018.12.05 추가('상품코드','자사코드' 택 1) 없을시 상품코드
    prod_id검색 샵플링상품코드번호(구분자"," 로 여러개가능)CDATA변수 미선언시 전체 (선언시 검색기간 무시함)
    sale_status검색 상품상태(구분자"," 로 여러개가능)CDATA변수 미선언시 전체
    대기중, 판매중, 품절, 판매중지, 판매종료, 삭제, 임시대기
    purchase_cd매입처 코드(구분자"," 로 여러개가능)CDATA변수 미선언시 전체 (18.6.19 추가)
    prod_fields출력 상품필드명(구분자"," 로 여러개가능)CDATAY상품조회필드 참고
    opt_yn옵션정보 출력여부[Y|N]CDATAY옵션정보 출력여부
    attri_yn고시정보 출력여부[Y|N]CDATAY고시정보 출력여부

    응답

    필드설명타입형식최대필수비고
    <rspns>
    <apiProdGather>
    login_id로그인IDCDATAY
    company_id고객사 아이디Y
    <goodsInfo> 반복
    goods_key샵플링 상품코드Y
    ptn_goods_cd고객사 상품코드CDATAY
    goods_var_name상품정보 변수명CDATA(상품조회 필드 기술서 변수 참조)
    <options> 반복 옵션정보 시작
    <optList> 반복 옵션 단수만큼 반복 (단품은 한번만 옴)
    title옵션명 (옵션항목명)CDATAY(단품은 "단품" 으로 표기)
    value옵션구성값(구분자 "," 로 구분)CDATAY(단품은 "단품" 으로 표기)
    optId샵플링 옵션코드(키)CDATA(구분 "," 로 구분) 2017.1101 추가
    optStatus판매상태(구분자 "," 로 구분)Y조합으로 B:판매, C:품절, X:미사용
    optQty현재고(구분자 "," 로 구분)Y조합으로 현재수량
    optVrtlQty가상재고(구분자 "," 로 구분)조합으로 가상재고수량
    optSaveQty안전재고(구분자 "," 로 구분)조합으로 안전재고수량
    optBundleQty묶음수량(구분자 "," 로 구분)조합으로 묶음수량
    optAmt추가금액(구분자 "," 로 구분)조합으로 추가금액 없으면 "0"
    optWeight무게 g단위(구분자 "," 로 구분)
    optBarcode바코드(구분자 "," 로 구분)
    optStoreMemo창고메모(구분자 "," 로 구분)CDATA(구분자 "," 로 구분)
    optNo옵션정렬순서(구분 "," 로 구분)CDATA(구분자 "," 로 구분)
    optPtnOptCd고객사 관리옵션코드(구분 "," 로 구분)
    optImgUrl옵션 이미지 urlCDATA(구분 "," 로 구분) 2017.03.22 추가
    optDescUrl옵션 상세설명 urlCDATA(구분 "," 로 구분) 2017.03.22 추가
    optOrgAmt옵션 원가 추가금액CDATA(구분 "," 로 구분) 2017.08.22 추가
    <pkgOptMappings> 반복 패키지 상품(goods_tp=S)의 옵션별 구성상품 - 별도 신청 업체만 출력
    <pkgOptMap> 반복 패키지옵션 매핑 단위
    optId옵션코드CDATA
    pkgTitle패키지 타이틀CDATA
    <pkgItems> 반복 패키지 아이템 목록 시작
    <pkgItem> 반복 패키지 아이템 단위
    prodId상품코드
    prodNm상품명CDATA
    optId옵션코드
    optValue옵션값CDATA
    price가격
    status상태
    real_cnt실재고수량
    vrtl_cnt가상재고수량
    mapCnt매핑수량
    <goodsAttri> 반복 상품고시정보 시작태그 (여러개 가능)
    <attriList> 반복
    code상품정보고시분류코드CDATAY(상품정보고시 분류코드참조)
    attri_var_name상품속성변수CDATA(상품정보고시 분류코드 속성 변수 참조)

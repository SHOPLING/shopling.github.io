    시작하기

    개요

    • 요청·응답 데이터는 XML, 문자셋은 UTF-8 입니다.
    • 모든 요청은 HTTPS POST 로 호출합니다.
    • 필드 기술서의 데이터 타입은 MySQL 기준입니다. 필수값이 아니고 해당사항이 없는 필드는 보내지 않아도 됩니다.
    • 타입이 CDATA 인 필드는 값을 <![CDATA[...]]> 로 감싸 보내 주세요.

    호출 방식

    각 API 는 두 가지 방식 중 하나로 호출합니다.

    mode방법
    2요청 본문(body)에 XML 을 그대로 담아 전송 (권장)
    POST https://api.shopling.co.kr/<API 경로>?mode=2 · Content-Type: text/xml; charset=UTF-8
    1요청 XML 을 올려둔 URL 을 전달하면 샵플링 서버가 그 URL 을 읽어 처리
    POST https://api.shopling.co.kr/<API 경로>?mode=1&xml_src_url=<XML 파일 URL>
    curl -X POST "https://api.shopling.co.kr/invoice/invoice_registration_api.phtml?mode=2" \
     -H "Content-Type: text/xml; charset=UTF-8" \
     --data-binary @request.xml

    인증

    모든 요청의 최상위 노드 아래에 다음 3개 값을 넣습니다. 값은 샵플링에서 발급합니다.

    필드설명
    login_id샵플링 로그인 ID
    company_id고객사 아이디
    api_auth_keyAPI 인증코드

    공통 오류 응답

    요청 전체가 처리되지 못하면 XML 대신 아래 문구가 평문으로 응답됩니다. 건별 처리 결과는 각 API 응답의 code / msg 로 확인합니다.

    응답 문구원인
    https 로 접속하시기 바랍니다.HTTP 로 호출
    인증 실패login_id · company_id · api_auth_key 불일치
    기간 만료API 또는 서비스 이용기간 만료
    요청전문 XML 오류입니다.mode=1 의 xml_src_url 을 읽을 수 없음

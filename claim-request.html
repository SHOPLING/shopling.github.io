    클레임요청처리

    샵플링 주문 클레임 처리 요청 하기

    POST https://api.shopling.co.kr/order/order_claim_req_api.phtml?mode=2 호출 방식

    요청

    필드설명타입형식최대필수비고
    <reqst>
    <apiClaimReq>
    login_id로그인IDCDATAY
    company_id고객사 아이디YshopPling 발급
    api_auth_keyAPI 인증코드YshopPling 발급
    <claimInfo> 반복
    ord_no샵플링 주문번호Y
    claim_status변경할 클레임 주문상태CDATAY클레임 처리 가능 상태 :
    신규주문,발송준비,발송보류,발송대기 → 취소접수
    취소접수 → 취소완료
    발송완료,주문출고완료 → 반품접수, 교환접수
    반품접수 → 반품수거완료
    교환접수 → 교환수거완료
    exchange_new교환접수시 신규주문생성여부CDATAY 시 교환주문으로 신규주문 생성함
    mall_claim_rsn2클레임 사유CDATA클레임 정보(클레임 아닐시 기재하지 않습니다.)
    교환사유 : 색상변경, 사이즈변경, 기타,배송오류, 상품파손, 옵션변경, 상품불량, 상품불만족
    반품사유 : 상품품절, 배송오류, 배송지연,단순변심, 기타, 상품불만족, 상품불량, 상품파손
    취소사유 : 상품품절, 기타, 단순변심,배송지연, 상품변경
    memo클레임내용CDATA클레임 정보(클레임 아닐시 기재하지 않습니다.)
    prod_use_status상품사용상태CDATA클레임 정보(클레임 아닐시 기재하지 않습니다.)
    알수없음, 미개봉, 개봉후미사용, 개봉후사용
    pickup_tp반품,교환수거방법CDATA클레임 정보(클레임 아닐시 기재하지 않습니다.)
    교환방법: 맞교환지시, 고객발송, 수거완료확인, 수거지시, 누락재출고, 전체재출고
    반품방법: 수거지시, 고객발송, 수거완료확인, 쇼핑몰수거
    dlvy_id회수택배정보 택배사 코드CDATA클레임 정보(클레임 아닐시 기재하지 않습니다.)
    택배사 코드 참조
    dlvy_no회수택배정보 운송장번호CDATA클레임 정보(클레임 아닐시 기재하지 않습니다.)
    dlvy_fee회수택배정보 택배비CDATA클레임 정보(클레임 아닐시 기재하지 않습니다.)
    enclose_amt동봉금액CDATA클레임 정보(클레임 아닐시 기재하지 않습니다.)

    응답

    필드설명타입형식최대필수비고
    <rspns>
    <apiClaimReqRst>
    login_id로그인IDCDATAY
    company_id고객사 아이디Y
    <claimInfoRst> 반복 샵플링 주문번호
    code성공,실패 결과코드CDATA
    msg성공,실패 결과메세지CDATA
    succs_cnt성공건수

    재고출고등록

    [E3] 상품출고관리 출고(일반) 전표 등록 (엑셀대량출고등록과 동일)

    POST https://api.shopling.co.kr/prod/stock_out_api.phtml?mode=2 호출 방식

    요청

    필드설명타입형식최대필수비고
    <reqst>
    <apiStockOut>
    login_id로그인IDCDATAY
    company_id고객사 아이디YshopPling 발급
    api_auth_keyAPI 인증코드YshopPling 발급
    strage_cd출고창고 코드Y[E] 창고관리에 등록된 사용중 창고코드
    detail_tp출고구분YO:정상 R:반품 E:교환 M:이동 S:실사 Z:기타
    inout_dt출고일자yyyymmdd미선언시 호출일자. 행별 inout_dt 가 있으면 그 값 우선
    invntry_nm전표명CDATA미선언시 "API 출고전표"
    memo전표 메모CDATA
    apply_yn재고반영여부Y:등록 즉시 재고반영 / N:미반영 등록(기본) - [E3] 상품출고관리에서 재고반영
    fail_tp오류처리방식A:한 건이라도 오류면 전체 미등록(기본) / P:오류건만 제외하고 등록
    <stockInfo> 반복 1회 최대 5,000건
    barcode바코드CDATAbarcode 또는 prod_id+opt_id 중 하나 필수 (barcode 우선)
    prod_id샵플링 상품코드number
    opt_id샵플링 옵션코드number
    qty출고수량numberY0 제외 정수
    unit상태CDATA"불량" 포함시 불량재고로 출고
    cust_cd매입처코드매입처(공급처) 코드. 매입처+출고일자가 같은 행끼리 한 전표로 등록
    loct_nm로케이션CDATA
    memo명세 메모CDATA
    inout_dt출고일자yyyymmdd

    응답

    필드설명타입형식최대필수비고
    <rspns>
    <apiStockOutRst>
    login_id로그인IDY
    company_id고객사 아이디Y
    <stockListRst> 반복 요청 stockInfo 순서대로
    seq요청 행번호number
    barcode바코드
    prod_id샵플링 상품코드number
    opt_id샵플링 옵션코드number
    invntry_no등록된 출고전표번호등록된 경우만
    code결과코드CDATA
    msg결과메세지CDATA
    succs_cnt성공건수
    fail_cnt실패건수

    요청 예시

    <?xml version="1.0" encoding="UTF-8"?>
<reqst>
   <apiStockOut>
      <login_id><![CDATA[shoppling]]></login_id>
      <company_id>S001</company_id>
      <api_auth_key>fgsddfgfkdgdkfgk</api_auth_key>
      <strage_cd>A001</strage_cd>
      <detail_tp>O</detail_tp>
      <inout_dt>20260929</inout_dt>
      <apply_yn>Y</apply_yn>
      <fail_tp>A</fail_tp>
      <stockInfo>
         <barcode><![CDATA[8801234567890]]></barcode>
         <qty>3</qty>
      </stockInfo>
      <stockInfo>
         <prod_id>100058</prod_id>
         <opt_id>2</opt_id>
         <qty>1</qty>
         <cust_cd>B001</cust_cd>
      </stockInfo>
   </apiStockOut>
</reqst>

      <stockListRst>

    결과코드

    000 : 정상
901 : 입력값 오류 (상품정보 누락, 코드·수량·매입처·일자 형식 오류)
910 : 대상 상품 없음 (재고관리 대상 상품이 아니거나 재고연결상품)
920 : 다른 행의 오류로 등록되지 않음 (fail_tp=A)
930 : 등록 실패
940 : 출고전표는 등록되었으나 재고반영 실패 (미반영 전표로 남음, apply_yn=Y)

※ 요청 전체 오류(인증 실패, 재고관리 미사용 업체, 창고·출고구분 코드 오류, 5,000건 초과 등)는 XML 이 아닌 안내 문구로 응답합니다.

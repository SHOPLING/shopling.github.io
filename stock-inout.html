    입출고전표조회

    [E1] 상품입고관리 · [E3] 상품출고관리 입출고전표 명세를 기간으로 조회 (전표 명세 1건 = 상품·옵션 1행)

    POST https://api.shopling.co.kr/prod/stock_inout_list_api.phtml?mode=2 호출 방식

    요청

    필드설명타입형식최대필수비고
    <reqst>
    <apiStockInout>
    login_id로그인IDCDATAY
    company_id고객사 아이디YshopPling 발급
    api_auth_keyAPI 인증코드YshopPling 발급
    start_dt조회 시작일자yyyymmddY
    end_dt조회 종료일자yyyymmddY조회기간 최대 31일
    date_tp기준일자구분A:입출고일자(기본) / B:재고반영일시 - 지난 날짜로 등록된 전표까지 빠짐없이 받으려면 B 로 마지막 수집 이후를 조회
    apply_yn재고반영여부Y:재고반영된 전표만(기본) / N:미반영 전표만 / A:전체
    strage_cd창고코드미선언시 전체 창고
    invntry_tp입출고구분I:입고 E:출고, 미선언시 전체
    detail_tp입출고상세구분O:정상 R:반품 E:교환 M:이동 S:실사 Z:기타, 미선언시 전체
    prod_id샵플링 상품코드number특정 상품만 조회할 때
    opt_id샵플링 옵션코드number특정 옵션만 조회할 때

    응답

    필드설명타입형식최대필수비고
    <rspns>
    <apiStockInoutRst>
    login_id로그인IDY
    company_id고객사 아이디Y
    total_cnt조회건수number
    <stockInoutInfo> 반복 전표 명세 1건당 1개. 기준일자 → 전표 → 명세 순
    invntry_no전표번호
    invntry_nm전표명
    inout_dt입출고일자yyyymmdd
    invntry_tp입출고구분I:입고 E:출고
    detail_tp입출고상세구분O:정상 R:반품 E:교환 M:이동 S:실사 Z:기타
    detail_tp_nm입출고상세구분명
    reg_tp생성구분O:주문(주문출고·반품입고) B:발주 S:일반(화면·엑셀·API 등록)
    apply_yn재고반영여부Y / N
    apply_dt재고반영일시yyyymmddhhiiss미반영이면 빈값
    strage_cd창고코드
    strage_nm창고명
    cust_cd거래처코드
    prod_id샵플링 상품코드number
    opt_id샵플링 옵션코드number
    ptn_goods_cd자사상품코드삭제된 상품이면 빈값
    ptn_opt_cd옵션자체관리코드
    barcode바코드
    opt_value옵션명
    qty수량number입고·출고 모두 등록된 수량 그대로 (입출고구분으로 증감 판단)
    body_tp상품상태G:정상 F:불량
    ord_no샵플링 주문번호주문 연계 전표만, 그 외 0
    memo명세 메모

   </apiStockInout>
</reqst>

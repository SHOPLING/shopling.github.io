    상품수정

    상품 수정 요청 (수정만 가능)

    POST https://api.shopling.co.kr/prod/prod_modify_api.phtml?mode=2 호출 방식

    요청

    필드설명타입형식최대필수비고
    <reqst>
    <apiProdMdy>
    login_id로그인IDCDATAY
    company_id고객사 아이디YshopPling 발급
    api_auth_keyAPI 인증코드YshopPling 발급
    partner_id제휴사 전용 (샵플링 발급)
    <goodsInfo> 반복 상품 정보 시작 태그(상품당1개)
    goods_key샵플링 상품코드Y존재하면 먼저 검색함 우선순의 첫번째 (수정 key)
    ptn_goods_cd고객사 상품코드CDATAY샵플링 상품코드가 없을시 검색함 우선순의 두번째 (수정key)
    goods_var_name상품정보 변수명CDATA(상품필드 기술서 변수 참조) 변수 미선언시 수정되지않음
    <options> 반복 옵션정보 시작 미선언시 수정되지않음
    optClear옵션삭제여부CDATAY: 삭제
    <optList> 반복 옵션 단수만큼 반복 (단품은 한번만 옴) 조합으로 매치되는 옵션만 수정합니다.
    title옵션명 (옵션항목명)CDATAY(단품은 "단품" 으로 표기)
    value옵션구성값(구분자 “,” 로 구분)CDATAY(단품은 "단품" 으로 표기)
    optStatus판매상태(구분자 “,” 로 구분)Y조합으로 B:판매, C:품절, X:미사용
    optQty현재고(구분자 “,” 로 구분)Y조합으로 현재수량
    optVrtlQty가상재고(구분자 “,” 로 구분)조합으로 가상재고수량
    optSaveQty안전재고(구분자 “,” 로 구분)조합으로 안전재고수량
    optBundleQty묶음수량(구분자 “,” 로 구분)조합으로 묶음수량
    optAmt추가금액(구분자 “,” 로 구분)조합으로 추가금액 없으면 “0”
    optWeight무게 g단위(구분자 “,” 로 구분)
    optBarcode바코드(구분자 “,” 로 구분)
    optStoreMemo창고메모(구분자 “,” 로 구분)CDATA(구분자 “,” 로 구분)
    optNo옵션정렬순서(구분 “,” 로 구분)CDATA(구분자 “,” 로 구분)
    optPtnOptCd자체관리옵션코드(구분 “,” 로 구분)
    optImgUrl옵션 이미지 urlCDATA(구분 “,” 로 구분) 2017.03.22 추가
    optDescUrl옵션 상세설명 urlCDATA(구분 “,” 로 구분) 2017.03.22 추가
    optOrgAmt옵션 원가 추가금액CDATA(구분 “,” 로 구분) 2017.09.06 추가
    <goodsAttri> 반복 상품고시정보 시작태그 (여러개 가능) 미선언시 수정되지않음
    <attriList> 반복
    code상품정보고시분류코드CDATAY(상품정보고시 분류코드참조)
    attri_var_name상품속성변수CDATA(상품정보고시 분류코드 속성 변수 참조) 변수 미선언시 수정되지않음
